# FoodHub - Food Ordering System

ICT 2209 Web Technologies Mini Project

## Technologies
- HTML
- CSS
- Bootstrap-ready structure (custom CSS used for simple implementation)
- JavaScript
- PHP
- MySQL

## Main Features

### Customer
- Register and login
- Browse available food
- Search and filter food
- Add food to cart
- Checkout with delivery details
- View order history and order status
- Contact the shop

### Shop Admin
- Admin login
- Dashboard
- Add food items
- Edit food items
- Delete food items
- Mark items available/unavailable
- View customers
- Delete customers
- View orders
- Accept/update/cancel orders

## Installation using XAMPP

1. Install XAMPP.
2. Copy the `food_ordering_system` folder into:
   `C:/xampp/htdocs/`
3. Start Apache and MySQL in XAMPP.
4. Open phpMyAdmin:
   `http://localhost/phpmyadmin`
5. Import `database.sql`.
6. Open:
   `http://localhost/food_ordering_system/`
